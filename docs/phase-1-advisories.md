# Phase 1 advisory remediation

Audit snapshot: 2026-10-28. Evidence: `pnpm audit --json` before/after, installed manifests/source and `pnpm-lock.yaml`. These are npm dependency advisories, not a complete container/Go/production vulnerability assessment. Reachability conclusions below are source-review assessments for Phase 1, not guarantees for future features.

The previous blanket explanation about major-version substitutions was incomplete: esbuild has an in-range fix and js-yaml has a same-major fix. Both are now updated. Four MinIO-chain advisories remain visible in the audit; none are suppressed.

## Version and compatibility evidence

- Original audit: 1 low, 5 moderate, 0 high/critical. Updated audit: **4 moderate, 0 low/high/critical**; exit status remains 1 because these four are unresolved.
- Registry metadata checked for Vitest, Vite, MinIO, js-yaml, decode-uri-component and stream-json. Installed Vite range confirmed the esbuild update; installed Swagger exact pin required the scoped js-yaml override.
- MinIO 8.0.7 is the latest registry stable version observed during this review and still declares the old parsing dependency ranges. Source inspection located query-string stringify calls in `dist/main/internal/client.js` and the JSONL parser import in `dist/main/notification.js`. No application call to `listenBucketNotification`, query-string parsing, stream filters, JSONC parsing or Assembler was found.
- Existing multer 2.5.0 and deepmerge-ts 8.0.0 overrides are unchanged from the original implementation. No broad new overrides or incompatible major substitutions were added in this remediation.
- Vitest **4.1.12** is a new root development dependency. It accepts the installed Vite 7 line and Node 24. Tests/builds run against the resolved lockfile, not an assumed compatibility claim.

Future recruitment features introduce untrusted inputs and must reassess these dependency paths before use. The four residual advisories and MinIO maintenance status remain implementation risks. Local remediation does not authorize production release or claim an independent audit PASS.
