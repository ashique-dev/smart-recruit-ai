# SmartRecruit AI

Multi-tenant AI-assisted recruiting screening SaaS. Initial implementation supports resume screening and structured **text-based** AI interviews; no WebRTC/media modules.

## Start with Codex (Astra Medium)
1. Open this folder as the Codex working directory.
2. Read `AGENTS.md`, `docs/MASTER_SPEC.md`, and `docs/PHASE_0.md`.
3. Run the Phase 0 kickoff prompt provided with this starter pack.
4. Review generated architecture documents before authorizing Phase 1.

The repository currently contains specification files only, by design.
